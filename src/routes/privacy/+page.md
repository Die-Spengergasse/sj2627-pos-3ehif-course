# Privacy

This site **does not store any data on a server**. There is no login, no cookies and no analytics or tracking.

- **Your progress** (units read, results of your practice rounds, settings) is stored only in your browser (`localStorage`, key `pos3hif:v1`). It only leaves your computer if you export it as a file yourself. Your teacher only sees it if you hand over that file.
- **Fonts and diagrams** are served by this site itself. No requests go to other providers.
- **Exercises** are downloaded from GitHub when you clone or update the exercises project, or download an exercise as a zip.
- The site is **hosted** on GitHub Pages. Like any web server, GitHub processes technical access data (e.g. your IP address); see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

You can delete your progress at any time by removing this site's data in your browser.
